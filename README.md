# STEP-CLASSES-PROJECTS
📘 STEP Classes – Java Assignments
📌 Overview

This repository contains the Java assignments given during the STEP Classes. The purpose of these assignments is to build a strong foundation in Java programming by practicing core concepts, problem-solving skills, and object-oriented programming.

🎯 Objectives

The main goals of these assignments are:

Understand Java syntax and structure

Practice problem-solving using Java

Learn Object-Oriented Programming (OOP) concepts

Develop logical thinking and coding skills

Prepare for academic and technical interviews
